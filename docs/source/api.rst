Radial-velocity likelihoods
---------------------------

Convenience helpers for applying the Laplace approximation to radial-velocity
(RV) likelihood functions, which are physical models used primarily in exoplanet
astrophysics. ``radvel`` is an optional dependency (``pip install "lapprox[rv]"``).
